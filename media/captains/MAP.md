## Fixture mapping guidance

- Match any fixture involving the team to that team's portrait file.
- For women's fixtures, prefer the `-women` portrait when available; fall back to the
  men's portrait of the same nation only if no women's artwork exists yet
  (currently: only Australia Women and Bangladesh Women have dedicated portraits).
- "A"-team fixtures (India A, Australia A) must use the abstract graphics, never a captain portrait.
- If a fixture involves a team with no portrait (e.g. Zimbabwe, Ireland, Netherlands),
  fall back to one of the hero-stadium backgrounds rather than a wrong team's portrait.
